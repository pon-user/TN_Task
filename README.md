# たぬタスク UX刷新版 v0.6.1

ユーザー実機フィードバック17項目をもとに再設計した React 19 / Vite 7 アプリ。

## 最重要：既存のリポジトリに重ねてアップロードする

このZIPは**差分置き換え用のファイルセット**です。既存リポジトリ `pon-user/TN_Task` のファイルを削除せず、ZIP内の各ファイルを同じパスに**上書き・追加**してください。既存の `public/icons/` にあるアイコン画像は ZIP には含めていません。削除するとホーム画面アイコンおよび、キャラクター画像読み込み失敗時の代替表示に影響します。

`.github/workflows/pages.yml` も入れてあります。現行の公開設定を維持したい場合は、既存ワークフローと見比べてください。GitHub Actions側は `npm install` → `npm test` → `npm run build` を実行する構成です。既存の lock ファイルがある場合は維持してください。

## 実装済み

- `ホーム` に「今日・期限超過／積み残し・未来」件数と XP。今日と超過を分離して表示。
- 単発の予定日と期限日、未設定状態、残り続ける超過。期限日が未指定の単発は予定日を超過判定の代替に使う（ラベルは積み残し）。
- 繰り返しは発生日別に独立した実施回を生成する。未完了分は次の予定に上書きされず残り続ける。見送りは指定した実施回のみに作用する。
- 登録先を `タスク管理` に一本化。単発・繰り返しとも同じ作成ダイアログ、分類・状態別一覧、スマホ向け表組みを用意。
- N週間／Nか月の開始日指定、月末補正（例：1/31→2/28→3/31）。既存ルールは履歴保全のため、タイトルと分類のみ編集可能。
- 完了済み、および一度完了歴のあるタスクは削除不可。既存データの XP は維持し、同じタスク／実施回に2度目の XP イベントを発生させない。
- 完了ボタンは中央寄せ SVG の大きなタップ領域。編集ダイアログの入力欄は狭い画面でも収まるレスポンシブ仕様。
- たぬの通知は約4.4秒で自動消去。下部メニューはアイコン＋短い日本語ラベル。
- 履歴は経験値ゲージ、勝利／ダメージ／連勝、称号の次目標、直近実績、戦闘再生／体験デモを統合。
- iOS SafariでSVGが読み込めない問題に対応するため、キャラSVG内部のPNGデータを直接表示する方式を採用。リモートに到達できない場合は既存ローカルアイコンにフォールバックする。
- 保存キーは既存 `pon_task_v1_snapshot` のまま。バックアップJSONから復元できる。

## 重要な前提・留保

- 既存データは基本的に維持するが、旧コードが既にまとめていた過去の繰り返し未実施回は、保存されていなければ**完全には復元できない**。新しい仕様は v0.6 使用開始以後に確実に適用される。
- 既存の `public/icons` は残す必要がある。敵画像はObsidian保管庫の公開URLへ依存する。たぬSVGは公開URLから取得して内部PNGを抽出する（オフライン描画にはローカル画像の同梱が必要）。
- 繰り返しの一時停止は過去の積み残しを保持する。停止期間中は新規実施回を増やさず、再開後の予定から生成する。
- 完了→取消→再完了でも、同一ソースは新規 XP イベントを再発行しない。ただし異なるタスクを無制限に登録する行為を完全防止するものではない。+1件ボーナスのゲームバランスは今後調整余地あり。
- レベル閾値・称号正式名称・279種の台詞実装は未確定。
- iPhone実機Safariの操作検証、実画像の描画検証は利用者側で必要。ここの自動テストはドメインロジックが中心。

## 戦闘の説明

朝6時以降のアプリ起動時に、前日6時～当日6時の進捗により戦闘を1回記録する。`完了 C`、`残り R`、`先取り F` から敵HP = C+R、攻撃力 = C+F を計算し、R−F が0以下なら勝利。R=0なら全クリ。履歴画面の「戦闘を見る」は結果の再生で、報酬や記録は変化しない。戦闘の発生していない初回は「戦闘を体験」でデモを見ることができる。
