# たぬタスク v0.8.1 — 午前4時基準の実績・戦闘に統一

スマホ向けReact 19 / Vite 7 タスク管理アプリ。公開用のソース、全32点のゲーム用ドット絵、アイコン、設計資料、テストを同梱した配布版です。

## この版の主な変更

- ホーム：大きなキャラ/XPのヘッダーを廃止して**日付→コンパクトな件数→今日のタスク→期限超過**を表示。
- 5タブ：ホーム／タスク管理／実績／履歴／設定。実績＝たぬの成長、履歴＝過去の行動。
- タスク管理：分類を除去。登録入口1つ。単発／繰り返しルールを各1行で一覧化。
- 登録：日付ピッカーの横はみ出し対策、必須未入力の専用エラーダイアログ。
- 戦闘：未確認の実戦記録を翌再表示可能にする。実戦／戦闘なし／デモを区別。全8体の敵がランダム登場。
- 画像：元の非公開Obsidian URLを読む方式を廃止して、公開アプリ内の32PNGへ置換。

**最新の変更:** [UPGRADE_4AM_v0.8.1.md](UPGRADE_4AM_v0.8.1.md)。

前回までの改修内容は [CHANGELOG_v0.8.md](CHANGELOG_v0.8.md)。
公開時の注意点は [UPLOAD_v0.8.md](UPLOAD_v0.8.md)。

## 起動・検証

```bash
npm install
npm test
npm run dev
npm run build
```

GitHub Pagesでは `.github/workflows/pages.yml` がnpmテスト・Viteビルド・公開を実行します。

## 保存データについて

同じ `pon_task_v1_snapshot` キーと schemaVersion 1 を維持し、既存データを引き継ぎます。端末ブラウザ内にローカル保存します。アップロード前にJSONバックアップを推奨します。

## 完了条件と留保

画像とコードは同じZIPに含まれます。単体テスト・静的検証の結果は実機合格を意味しません。iPhone Safariの実機レビューは別工程です。

過去の設計・監査・変更履歴は旧版の経緯を残すためZIPに同梱していますが、最新の変更点は `UPGRADE_4AM_v0.8.1.md` を優先してください。
