# たぬタスク v0.8.1 — 午前4時基準の実績・戦闘に統一

スマホ向けReact 19 / Vite 7 タスク管理アプリ。公開用のソース、従来のゲーム用ドット絵、追加した36種類のたぬ画像、アイコン、設計資料、テストを同梱しています。

## この版の主な変更

- ホーム：大きなキャラ/XPのヘッダーを廃止して**日付→コンパクトな件数→今日のタスク→期限超過**を表示。
- 5タブ：ホーム／タスク管理／実績／履歴／設定。実績＝たぬの成長、履歴＝過去の行動。
- タスク管理：分類を除去。登録入口1つ。単発／繰り返しルールを各1行で一覧化。
- 登録：日付ピッカーの横はみ出し対策、必須未入力の専用エラーダイアログ。
- 戦闘：未確認の実戦記録を翌再表示可能にする。実戦／戦闘なし／デモを区別。全8体の敵がランダム登場。
- 画像：元の非公開Obsidian URLを読む方式を廃止して、公開アプリ内の画像へ置換。

## 2026-11-03 追加：たぬ画像36種類・画面遷移時ランダム表示

- 承認済みの透過PNG36枚を `public/sprites/tanu/` 直下に追加。
- ホーム・タスク管理・実績・履歴・設定は、画面遷移のたびに36種類からランダムでたぬを選択。直前と同じ画像が連続しないようにする。
- 選ばれた画像はその画面を表示している間は固定。タスク操作や時計更新による再描画では変化しない。同じタブを押し直すだけでは再抽選しない。
- 戦闘モーダルのたぬは攻撃・勝利・敗北等の状態に合わせた既存の演出を維持。
- タスク・XP・戦績のデータや保存形式は変更しない。
- 画像が読み込めない場合は、従来のたぬ画像にフォールバック。

対応表・アップロード先・検証手順は [docs/tanuki-asset-pipeline.md](docs/tanuki-asset-pipeline.md) を参照。

## 起動・検証

```bash
npm install
npm test
npm run dev
npm run build
```

GitHub Pagesでは `.github/workflows/pages.yml` がnpmテスト・Viteビルド・公開を実行します。
PRの画像検証は `.github/workflows/verify-pr.yml` が実行します。PR #13検証ではテスト77件成功、ビルド成功、36枚の画像同梱、390px幅のChromiumホーム画面スモークテスト成功を確認しました。追加の画面遷移ランダム表示は5画面の遷移と画像読み込みをChromiumで検証します（結果は対象PRのActionsを参照）。

## アプリアイコン（既存のケガたぬ）

- 2026-11-03より、既存の `public/sprites/tanu/tanuki_injured.png` をアプリアイコンに利用。32/180/192/512pxの各サイズを開発・ビルド時に自動作成します。

## 保存データについて

同じ `pon_task_v1_snapshot` キーと schemaVersion 1 を維持し、既存データを引き継ぎます。端末ブラウザ内にローカル保存します。アップロード前にJSONバックアップを推奨します。

## 完了条件と留保

単体テスト・静的検証・Chromiumスモークテストの成功は、iPhone Safari実機の合格や全画面目視確認を意味しません。iPhone Safariの実機レビューは別工程です。

過去の設計・監査・変更履歴は旧版の経緯を残すため同梱しています。午前4時基準に関する最新の変更点は `UPGRADE_4AM_v0.8.1.md`、たぬ画像の現行配置は `docs/tanuki-asset-pipeline.md` を優先してください。
