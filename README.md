# たぬタスク P04 初期実装 v0.1

React 19 / Vite 7。独立したタスク管理アプリの**動作する初期実装**です。既存の習慣アプリを変更せず、保存キーは `pon_task_v1_snapshot` です。

## 起動
`npm install` → `npm run dev`。テストは `npm test`、公開用の静的ビルドは `npm run build`。新規GitHub Pagesリポジトリで `dist/` を公開する場合に使えます。Viteの `base:'./'` によりサブパス公開を想定しています。

## 今回実装
- 4タブ（今日／一覧／履歴／設定）、単発タスクの登録・編集・完了・取消・削除
- 予定日と期限日、今日の積み残し、当日基礎XP残額配分＋初回15＋完了1件1XP
- 朝6時の戦闘記録、先取り攻撃、勝利と全クリの分離、踏ん張りHPのLv5/15/30/50閾値
- 勝利14・ダメージ19の称号閾値、勝利数／累計ダメージ／平均消化率
- ローカル保存、JSONバックアップ・復元、純粋ロジックの自動テスト

## v0.2 敵キャラ・たぬドット絵統合
- Obsidianの素材台帳 v1.1 にあるたぬ15種類のうち、実装で使う12種類を参照。敵8体・各3ポーズ（合計24PNG）を登録。
- 6時戦闘で敵をランダムに1体選び、`enemyId`をBattleRecordに保存。再描画や再起動で別の敵に変わらない。
- 敵の通常／勝利／敗北と、たぬの構え／攻撃／被弾／結果を戦闘フェーズで切替。
- キャラクターの見た目の大きさを揃えるため、両者を固定のステージに収めて `object-fit:contain` と `image-rendering:pixelated` を適用。小画面ではステージを縮小。元画像を非整数倍率で引き延ばすと機種によって見た目に差が出る可能性があり、iPhone Safariでの実機確認が必要。
- **画像の実体はGitHub上のObsidian保管庫からHTTPSで参照**。ZIPにバイナリ画像は同梱していないため、表示にはインターネット接続とGitHubの画像URLへのアクセスが必要。オフライン対応や画像読み込み失敗時の代替表示は今後の課題。
- 画像URLの定義は `src/domain/assets.js`。画像ファイル名は台帳の登録済みファイル名をそのまま使用。

## v0.4：N週間・Nか月間隔

一覧→繰り返しを追加でN週間またはNか月に1回を選択。登録日を初回予定日・基準日とする。遅れて完了しても実施日ではなく予定日を基準に次回を算出する。未完了は1回分のみ持ち越し。月末補正後も元の基準日（31日など）を維持する。

## v0.5：37称号を完成

勝利14・累計ダメージ19・連勝2（3/7日）・平均消化率2（7戦80%以上、20戦90%以上）の計37種類を解放判定に接続。勝利には先取り攻撃による討伐を含むが、全クリは別指標。戦闘のない日は連勝を途切れさせる。称号名は暫定表記。画像・セリフの完全統合とiPhone実機評価は未対応。
